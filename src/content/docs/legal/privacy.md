## 1. Overview

semrel.io and registry.semrel.io are operated by the SemRels open source project.
We are committed to protecting your privacy. This page explains what data is collected, why, and how long it is retained.

## 2. Data we collect

### 2.1 Documentation site (semrel.io)

The documentation site is a statically generated site served via CDN (GitHub Pages / Cloudflare Pages).

- **Server logs:** The CDN provider may collect standard HTTP access logs (IP address, browser, requested URL, referrer). These logs are retained according to the provider's policy and are not processed by us for analytics.
- **No cookies** are set by the documentation site itself.

### 2.2 Plugin Registry (registry.semrel.io)

| Data | Purpose | Retention |
|---|---|---|
| Plugin download counts | Usage statistics shown in the registry UI | Indefinitely (aggregate counters only) |
| Plugin view counts | Usage statistics shown in the registry UI | Indefinitely (aggregate counters only) |
| Authentication tokens (admin) | Access control | Session duration only; not stored server-side |
| GitHub OAuth login (optional) | Admin authentication | GitHub handle stored for attribution; deletable on request |

The registry does **not** set tracking cookies and does **not** use third-party analytics.

## 3. Cookies

A cookie banner is displayed on first visit to registry.semrel.io.
The only cookies stored are functional session cookies required for admin authentication.
No advertising or tracking cookies are used.

## 4. Third-party services

- **GitHub** — Repository hosting and OAuth provider. Subject to [GitHub's Privacy Policy](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
- **CDN/Hosting provider** — May process access logs as described in §2.1.

## 5. Your rights

Under applicable data protection law (GDPR where applicable) you have the right to access, rectify, or delete personal data we hold about you. Contact us at [hello@semrel.io](mailto:hello@semrel.io) to exercise these rights.
