## Warum semrel statt semantic-release?

<CardGrid>
  <Card title="Kein Node.js — niemals" icon="approve-check">
    semrel wird als **einzelne statische Binärdatei** für Linux, macOS und Windows ausgeliefert. Kein `npm install`, keine `node_modules`, kein V8-Kaltstart. Alpine-Container, air-gapped Pipelines und minimale Runner funktionieren ohne jedes Setup.
  </Card>
  <Card title="Automatisches SemVer aus Conventional Commits" icon="magnifier">
    semrel analysiert jeden Commit seit dem letzten Tag und berechnet den korrekten `major`-, `minor`- oder `patch`-Bump — ohne menschliche Entscheidung, ohne manuelle Changelog-Bearbeitung.
  </Card>
  <Card title="Supply-Chain-sicher by default" icon="padlock">
    Jedes offizielle Release ist mit **Sigstore Cosign** signiert, enthält **CycloneDX + SPDX SBOMs** und trägt **SLSA Level 1** Provenance-Attestierung. Bereit für NIS2-, DORA- und Cyber-Resilience-Act-Anforderungen.
  </Card>
  <Card title="Air-gap & regulierte Umgebungen" icon="server">
    Das `.semrel/plugins/`-Verzeichnis einmalig cachen. Danach sind während der CI-Ausführung null ausgehende Netzwerkverbindungen erforderlich. Vollständig kompatibel mit eingeschränkten, air-gapped Enterprise-Pipelines.
  </Card>
  <Card title="Vollständig plugin-basierte Pipeline" icon="puzzle">
    Jeder Schritt — Condition, Analyzer, Generator, Updater, Provider, Hook — ist eine austauschbare Subprozess-Binärdatei. Schreibe Plugins in **Go, Python, Rust, Node.js** oder jeder anderen Sprache. Kein Lock-in.
  </Card>
  <Card title="Monorepo-fähig" icon="code-branch">
    Versioniere mehrere unabhängige Module in einem Repository, jedes mit eigener `.semrel.yaml`, Tag-Serie und Release-Lifecycle.
  </Card>
  <Card title="Schnell in großen Repositories" icon="rocket">
    Kompiliertes Go gegenüber einem Multi-Hundert-Pakete-Node.js-Baum. semrel traversiert `git log` und ruft Forge-APIs nebenläufig ab — keine 35-minütigen CI-Timeouts.
  </Card>
  <Card title="Open Source · Apache 2.0" icon="open-book">
    Offen entwickelt auf [SemRels/semrel](https://github.com/SemRels/semrel). Dauerhaft kostenlos, kein Pro-Tarif, keine Bezahlschranke für Monorepo- oder Enterprise-Features.
  </Card>
</CardGrid>
